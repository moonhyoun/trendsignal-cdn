01먼저, 이 문서가 무엇인지

성공담이 아닙니다. 아직 성공하지 않았기 때문입니다.

인스타그램 카드뉴스 계정 하나를 거의 전부 자동화했습니다. 뉴스를 고르는 것도, 카드 10장을 만드는 것도, 인스타그램에 올리는 것도 사람 손이 닿지 않습니다. 한 달 동안 22편이 그렇게 나갔습니다.

그리고 팔로워는 5명입니다. 그중 대부분이 가족입니다.

그래서 이 문서는 두 가지를 담습니다
  • 작동하는 것 — 실제로 돌아가는 파이프라인의 구조와 순서
  • 작동하지 않은 것 — 자동화가 해결해주지 못한 문제들

두 번째가 더 중요하다고 생각합니다. 자동화 콘텐츠는 대개 "이렇게 하면 됩니다"에서 끝나는데, 실제로 해보면 기술이 끝나는 지점부터가 진짜 문제였습니다.

자동화는 손이 가던 자리를 지우고, 그 자리에서 사람이 보던 눈도 같이 지웁니다. 무엇을 자동화할지보다 어디서 멈출지를 먼저 적어야 했습니다.

02전체 구조 — 6단계

한 편이 나오기까지 거치는 과정입니다.

1
뉴스 수집국내 언론사 13~14곳의 RSS를 긁어 최근 이슈를 모읍니다. 제목만으로는 카드를 못 만들기 때문에 본문까지 추출합니다.
2
주제 선정 · 구성 설계AI가 후보 5개를 제안하고 타깃 적합도를 매깁니다. 이미 다룬 주제는 제외하고, 직전 편과 같은 카테고리는 순위를 내립니다.
3
카드 10장 + 캡션 생성제목·본문·체크리스트·캡션·해시태그를 한 번에. 구조는 고정입니다 — 커버 / 도입 / 본문 6장 / 체크리스트 / 브랜드.
4
이미지 렌더링카드 10장(1080×1350)과 릴스 4~5장(1080×1920)을 그립니다. 디자인 규칙이 코드에 박혀 있어 편마다 흔들리지 않습니다.
5
자동 검사강조색이 2개인지, 출처가 빠졌는지, 숫자가 카드와 캡션에서 다른지. 실패가 하나라도 있으면 발행으로 못 넘어갑니다.
6
인스타그램 발행이미지를 공개 URL에 올린 뒤 API로 캐러셀을 게시합니다. 게시가 끝나면 임시 이미지는 지웁니다.
사람이 반드시 개입하는 곳은 세 군데입니다
  • 주제 확정 (후보 5개 중 고르기)
  • 카드 10장 미리보기 확인 후 승인
  • 발행 직전 최종 확인 — "10장을 눈으로 보셨습니까?"

이 세 개를 없앨 수도 있었지만 남겼습니다. 이유는 04에서 설명합니다.

03무엇으로 만들었나

특별한 도구는 없습니다. 조합이 전부입니다.

단계쓴 것 · 비용
뉴스 수집언론사 RSS · 무료. 본문 추출이 핵심인데 언론사마다 HTML 구조가 달라 손이 많이 갑니다
글 생성생성형 AI API · 사실상 무료 구간. 분당 요청 제한에 자주 걸려 가벼운 모델로 내려왔습니다
이미지 렌더브라우저 자동화 + 캔버스 · 무료. 디자인을 코드로 고정하면 편마다 품질이 흔들리지 않습니다
검사자체 검사 스크립트 · 무료. 이게 없었으면 사고가 그대로 발행됐습니다
이미지 호스팅공개 저장소 · 무료. 인스타 API가 공개 URL만 받기 때문에 필요합니다. 발행 후 삭제
발행인스타그램 그래프 API · 무료. 비즈니스/크리에이터 계정과 페이스북 페이지 연결이 필요합니다

발행이 실제로 일어나는 순서

캐러셀(여러 장) 발행은 "이미지 올리기" 한 번으로 끝나지 않습니다.

  • 카드 10장을 각각 공개 URL로 올린다
  • URL이 실제로 열리는지 확인한다 (바로 안 열리는 경우가 있습니다)
  • 장마다 컨테이너를 만든다 — 10개
  • 10개를 묶어 캐러셀 컨테이너를 만들고 캡션을 붙인다
  • 준비 완료 상태가 될 때까지 기다린다
  • 게시 요청을 보낸다 → 이때 실제로 올라간다

중간에 끊기면 반쪽짜리 게시물이 남을 수 있습니다. 그래서 실패하면 올려둔 임시 이미지를 되돌려 지우는 처리를 넣었습니다.

04막혔던 지점 다섯

여기부터가 이 문서의 본론입니다.

① 릴스는 끝까지 자동화하면 손해였습니다

API로 릴스를 올리면 인기 음원을 붙일 수 없습니다. 앱 안에서만 오디오 라이브러리에 접근되기 때문입니다. 그런데 이 계정에서 도달의 대부분은 릴스에서 나왔습니다. 초기 6편 기준 카드뉴스 도달이 5일 때 릴스는 575였습니다.

그래서 릴스는 손에 남겼습니다. 끝까지 자동화하는 것과, 끝까지 자동화해도 되는 것은 다른 일입니다.

② AI가 만든 숫자는 반드시 다시 확인해야 합니다

같은 지표가 카드에서는 A, 본문에서는 B로 적힌 적이 있습니다. 확인되지 않은 수치가 "지웠는데 네 번 되살아난" 일도 있었습니다. 그래서 숫자가 들어간 장은 출처를 반드시 표기하고, 카드·캡션·릴스의 같은 숫자가 다르면 검사에서 실패하도록 만들었습니다.

③ 액세스 토큰은 60일마다 끊깁니다

인스타그램 API 장기 토큰의 수명은 60일입니다. 자동 갱신이 없으면 어느 날 갑자기 발행만 실패합니다. 코드는 멀쩡한데 권한이 죽어 있어 원인 찾기도 헷갈립니다. 만료일을 미리 적어두고 알림을 걸어두세요.

④ 검사기를 만들었더니, 검사기를 믿게 되더군요

자동 검사는 강력했지만 조용히 건너뛴 항목이 있었습니다. 통과처럼 보였는데 실제로는 검사되지 않은 것이었습니다. 자동화의 진짜 위험은 틀리는 게 아니라, 사람이 더 이상 보지 않게 되는 것이었습니다.

⑤ 만드는 속도가 빨라져도 반응은 빨라지지 않습니다

가장 크게 배운 것입니다. 편수를 늘릴 준비는 끝났는데, 반응이 없는 상태에서 편수를 늘리면 반응 없는 편이 더 빨리 쌓일 뿐이었습니다.

06따라 하실 분에게

전부 만들 필요는 없습니다. 순서만 지키면 됩니다.

1계정을 비즈니스 또는 크리에이터로 바꾸고 페이스북 페이지를 연결합니다. 이게 안 되면 API 자동 발행은 시작조차 못 합니다.
2카드 디자인 규칙을 먼저 글로 적습니다. 색·여백·폰트·장 구조. 코드보다 이게 먼저입니다.
3수동으로 다섯 편을 직접 만들어 봅니다. 손으로 해보지 않은 공정은 자동화해도 어디가 틀렸는지 모릅니다.
4그다음 자동화합니다. 어디서 멈출지를 먼저 정하고 시작하세요.
5그리고 사람을 만나는 시간을 따로 잡으세요. 이건 자동화되지 않습니다.
